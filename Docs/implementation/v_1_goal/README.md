# V1 goal: dependable use

Drafts for review. Nothing in this folder authorizes implementation until that document has been reviewed and tightened.

Two goals share one roadmap and keep separate completion criteria:

1. **Dependable.** A named behavior, on a named version, under named conditions, with the evidence that supports it and the evidence still missing.
2. **Easy to use.** A person can select data, prepare it, configure an experiment, run or resume it, inspect and compare results, freeze a candidate, and rehearse it in paper without reconstructing commands, paths, and notebook state from memory.

Reusable boundaries connect the two. A capability is reusable when another strategy, and research, paper, and live, can use it through the same rules and the same evidence. A new interface or a broad refactor does not, by itself, complete either goal.
